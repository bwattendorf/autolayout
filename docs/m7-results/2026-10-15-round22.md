## Analysis
- The result did not change: the parallel fold reproduces the sequential choice, as the totals and the two-board lines show. I did not diff every board's output file against Round 21, only the two-board files and the CSV columns.
- The speed-up is 1.4x in total (2142 -> 1342 s), less than the 3.8x on c4, because most of the time on other boards is a single attempt or already-clean boards. The Round 21 slowdown (+13%) is gone; some of it was probably machine load then (not tested separately).
- Cost: the parallel attempts raise peak memory (up to four routes at once on boards that need the whole portfolio) and do the work of attempts the sequential loop would have skipped. Docker was running during this batch and nothing was stopped. Peak memory was not measured.
